# Core requirements. Python 3.10 or newer.
#
#     python -m pip install -r requirements.txt
#
# Versions are pinned so a server installs what the tests were run against.
# Without pins a fresh install picks up whatever is current, which is how you
# end up debugging a combination nobody has run: pandas 3 in particular is a
# major release with breaking changes, and every CSV and Excel file this app
# reads goes through pandas.
#
# To move to newer versions: raise them here, run pytest, and only then hand
# the file to whoever hosts the app.
#
# The three tool libraries are not listed here. They come from GitHub, so a
# network that cannot reach github.com would otherwise break this install too.
# See requirements-flatten.txt, requirements-folder.txt and
# requirements-emails.txt. Each tool is optional; the app starts without them
# and marks that tab unavailable.
