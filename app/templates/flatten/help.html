About flattening

Flattening turns a fillable PDF into a fixed one. The values stay visible exactly where they were, but they stop being editable fields, so a form filler cannot change them and Acrobat's "Prepare Form" tool will not re-detect or delete them.

What you get back

A ZIP containing every flattened PDF, arranged in the same folder structure you picked, plus a file-by-file report named Flatten_Report.csv. Each document ends up in one of three states.

StateWhat it meansIn the ZIP?
Flattened The result was checked against the original and nothing moved or disappeared. Yes
Needs review No engine produced a result that passed the check, so the closest attempt was kept. The report says what looked wrong, for example that a page lost part of its content. Open these and confirm they are acceptable. Yes
Failed Every engine failed outright, usually because the file is corrupt or password protected. The reason is in the report. No

Limits

  • Up to {{ max_files }} files in one batch.
  • Up to {{ max_file_mb }} MB per file, and {{ max_total_mb }} MB in total.
  • Only files ending in .pdf are uploaded; anything else in the folder is ignored.
  • Runs and their downloads are deleted from the server after 24 hours.

Common problems

Everything comes back as "needs review"
Try turning on "allow rasterising as a last resort". It always reproduces the look of the page, at the cost of the text no longer being selectable or searchable.
A file failed and cannot be opened afterwards
It is most likely password protected or damaged. Open it yourself first and re-save it.
The choose-a-folder button does nothing
Folder picking needs Chrome or Edge. In another browser, use "pick individual files" instead.
Links stopped working
They should not: links are deliberately left clickable. If a link really is gone, report the file so it can be looked at.
