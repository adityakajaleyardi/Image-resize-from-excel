Emails to HTML and Images

The source system stores an email body compressed and encoded, so it is unreadable in any export you pull from the database. This turns each one back into the HTML page it was, and optionally takes a screenshot of it.

What to upload

One CSV or Excel export, one row per email. Two columns matter: the one holding the stored body, and the one holding the record id, which becomes the output filename.

LayoutBody columnName column

Legacy ExcelsEmailMessagehHistoryId

Leave the setting on Detect from the file and the headings decide which of the two it is. Choosing the wrong one by hand is the most common reason a run fails before it starts, which is why detecting is the default.

What you get back

The ZIP holds two folders, plus a log if anything failed:

  • html/ — one .html file per email, named after its record id.
  • images/ — one .jpg screenshot per email, if you asked for them.
  • Failed_Records.csv — only written when something failed.

The width of each screenshot is read from the email itself, so a narrow newsletter and a full width template come out at the sizes they were designed for.

What each outcome means

StateMeaning
Converted The body decoded and the files were written.
Failed Usually an empty body, a value that is not a compressed email, or a blank record id. One bad record never stops the run: the rest carry on and the failures are listed on the results card and in the download.

Worth knowing

  • Screenshots take roughly a second each, so a few thousand emails is an hour or more. Leave the tab open; the progress bar keeps counting and you can cancel at any point and still download what was produced.
  • Turning screenshots off is much faster and is worth doing if you only need to read the emails rather than look at them.
  • Long runs queue against each other rather than against the other tools, so starting a big export will not hold up someone flattening a PDF.
  • Row numbers in the log are spreadsheet line numbers, so the first email is row 2.
  • Decoded emails contain resident names, addresses and lease details. A finished run is deleted from the server after {{ tool_retention_hours }} hours, sooner than the other tools, so download the ZIP while you have it and keep it somewhere appropriate.
