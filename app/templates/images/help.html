How rows are handled

  • Rows with Active/Inactive set to Inactive are skipped.
  • Images are saved into a folder named TargetProperty__DocType.
  • If a download fails, the run continues and the row is listed in the failed log.
  • Full Path must point at {{ allowed_hosts }}. Addresses anywhere else are refused without being contacted, so the server cannot be used to reach other machines on the network.

Sizing

With manual sizing off, the target size comes from the iType column and the property type. Images are only ever scaled down, never enlarged, and portrait images are cropped slightly at the top and bottom first so they are not reduced to a sliver.

Common problems

"The source file is missing required columns"
A column name does not match exactly. Compare yours against the template, watching for a missing full stop in Doc. Type.
Rows fail with "could not be downloaded"
The URL in Full Path is wrong, or the image has been removed. The processor also retries the CDN addresses before giving up.
Rows fail with "downloads from ... are not allowed"
The URL points somewhere other than {{ allowed_hosts }}. Only those domains can be downloaded from. Ask whoever hosts the app if you need another source added.
The download is missing images
Check the process log in the ZIP. Every row is listed there with either its new path or the reason it failed.
Files are larger than expected
Only JPEGs are compressed to the size limit. PNGs are saved losslessly, so they can exceed it.
