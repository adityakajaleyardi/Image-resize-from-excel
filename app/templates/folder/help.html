Images from Folder

Takes a folder of property images, resizes each one to the rule for its document type, renames it to the Yardi convention and files it back into the same folder structure.

How the folder must be arranged

Pick the folder that holds your property folders. Inside it, every image must sit exactly two levels down: a property code folder, then a document type folder, then the image. 

Images to process/
  p1812741/
    UnitImage/
      studio-plan.jpg
    PhotoGallery/
      pool.jpg
  p1900233/
    PropertyLogo/
      logo.png

Document type folder names are matched ignoring case and spaces, so UnitImage, unit image and Unit Image are the same thing. Anything filed at the wrong depth is listed back to you and left out of the run.

Unit images

One floor plan is usually shared by many apartments, so a unit image is cross referenced against three lookup files and one output is produced per apartment, each carrying that apartment's HMY id. Expect far more files out than in: a batch of 48 images can produce well over a thousand.

  • UnitMapping.csv
  • CompanyUnitSummery.csv
  • PropertyList-Property.csv

These hold live property data, so they are uploaded with each run rather than kept on the server. If you are not processing unit images you can leave all three empty.

What each outcome means

StateMeaning
Processed The image was resized, renamed and written to the download.
No matching units A unit image that no apartment claimed, or whose apartments have no usable HMY. This is not an error, but nothing is produced for it.
Failed The file could not be read. The rest of the batch carries on regardless.

Worth knowing

  • Everything comes out as .jpg, except favicons, which become 64x64 .ico.
  • Transparent PNGs are flattened onto an opaque background.
  • When two family linked properties share a source filename the same target is produced twice. The later one wins, which is what the original tool did.
  • The download always includes Process_Log.csv, the record to reconcile against.
  • Folder picking needs Chrome or Edge.
  • Downloads are deleted after 24 hours.
