How a run works

  • Choose your files, check the settings, then start the run.
  • Progress is reported line by line while it works. One bad file is recorded and the rest of the batch carries on, so a single problem never stops the job.
  • When it finishes you get a ZIP of the results and a CSV report listing every item with either its new name or the reason it was left out.
  • A run can be cancelled at any point. Whatever finished before that is still downloadable.
  • Runs are deleted from the server after {{ retention_hours }} hours, so download what you need on the day. Emails to HTML and Images clears up sooner than that, because what it produces is personal data; its own help page says how long.

If something goes wrong

  • Read the report in the ZIP first. Nearly every failure explains itself there.
  • Each tool's help page lists the problems that come up most often for that tool.
  • Folder picking needs Chrome or Edge. Other browsers can only take individual files.
  • If a tool says it is not installed on this server, the machine hosting the app is missing a library. Whoever hosts it can install it; the version below says which are present.
